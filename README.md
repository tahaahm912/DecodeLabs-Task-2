# 💰 Monthly Expense Tracker (Python + JSON)

A simple command-line Python project that helps users track monthly expenses using JSON file storage. It allows adding expenses, viewing monthly totals, and analyzing overall spending in a structured way.

---

## 📌 Features

- Add expenses month-wise
- Select month from a clean menu (no manual typing errors)
- View expenses for a specific month
- View all stored expenses
- Calculate monthly total spending
- Calculate overall total spending
- Persistent storage using JSON file

---

## 🛠️ Tech Stack

- Python 3
- JSON (data storage)
- File Handling (read/write operations)
